# 1. 理论真正的硬核心

结构生力理论最重要的东西并不是“螺旋图形”，也不是“第五种力”。

**单元 → 关系 → 结构 → 流动 → 反馈 → 记忆 → 演化 → 层级跃迁**

其中：

* **单元**：构成系统的基本成分。
* **关系**：单元之间的连接、约束、作用。
* **结构 S**：单元 + 关系 + 边界 + 层级 + 动态规则形成的整体组织状态。
* **能量 E**：使状态发生改变的物理资源。
* **信息 I**：能够区分状态、约束状态转移并影响未来演化的结构差异。
* **流 F**：能量、物质、信息在结构中的传播。
* **反馈**：系统结果重新作用于系统本身。
* **记忆 M**：过去结构和交互留下、能够影响未来的状态残留。
* **生力 V**：结构在环境与流动作用下表现出的维持、恢复、适应、扩展、重构以及产生新结构的综合有效能力。
* **层级跃迁 L**：原有层级中的大量相互作用形成新的、具有相对独立状态变量和规则的宏观层级。

所以：

> **结构产生生力，生力重塑结构。**

# 3. 信息螺旋

普通循环：

**A → B → C → A**

信息螺旋：

**A₀ → B₀ → C₀ → A₁ → B₁ → C₁ → A₂……**

表面上重新回到类似状态 A，

实际上：

**A₁ ≠ A₀**

因为系统已经携带上一轮留下的信息。

因此真正定义“螺旋”的，不是几何上必须长得像螺旋，而是：

**递归 + 记忆 + 非完全重复 + 状态漂移。**

形式上：

[  
M_{t+1}=R(M_t,X_t,F_t)  
]

[  
X_{t+1}=G(X_t,M_{t+1},E_t)  
]

只要过去改变了未来重新进入同类状态时的内部条件：

[  
X_{t+k}\neq X_t  
]

这个循环就在状态空间中变成了“螺旋”。

所以：

> **螺旋是带历史的循环。**

这比“宇宙里到处存在几何螺旋”更接近信息螺旋真正有价值的含义。

# 13. IST —— Information Spiral Transformer

IST 的原始思想：

把长序列划成 Chunk：

[  
C_1,C_2,...C_n  
]

每处理一个 Chunk：

[  
M_{t+1}=Writer(M_t,C_t)  
]

当前 Chunk：

[  
H_t=Transformer(C_t,Read(M_t))  
]

Memory 因此沿时间递归：

[  
M_1\rightarrow M_2\rightarrow M_3...\rightarrow M_n  
]

核心目标：

**固定或缓慢增长的状态，承载不断增长的历史。**

这对应结构生力中的：

> **历史 → 结构印记 → 当前结构。**

# 14. IST 演化路线

## v0.1

Persistent Memory。

证明：

* Memory 可以跨 Chunk。
* 不同层 Memory 具有不同作用。
* zero/reset/swap 等因果干预会破坏任务结果。
* 因此模型确实在使用递归状态，而不是伪相关。

核心突破：

**“递归状态可以工作。”**

---

## v0.2

Fast / Slow / Episodic Memory。

尝试把历史高度压缩为匿名槽位。

问题：

自然语言 held-out 泛化明显失败。

重要认识：

> **仅仅知道“有什么信息”不够，还必须知道信息来自哪里。**

匿名压缩破坏了：

**Source Identity / 来源身份。**

这是 IST 最重要的一次失败经验。

---

## v0.3

Source Token Memory。

开始保留：

* 来源 Token hidden state
* Token ID
* absolute position
* source Chunk
* selection score
* query read weight

系统开始从：

**抽象匿名记忆**

转向：

**有来源、可追溯的证据记忆。**

---

## v0.5

核心结构进一步收敛为两条记忆通路：

### Evidence Memory

负责：

**具体事实、来源身份、Token证据、可追溯历史。**

### Core State

负责：

**递归抽象、历史压缩、整体状态演化。**

结构：

```
历史 Chunk
     │
     ├── Evidence Memory
     │       └── 保存具体证据
     │
     └── Core State
             └── 压缩长期状态

Current Query
     │
     ├── Read Evidence
     ├── Read Core
     │
     └── Gated Fusion
             ↓
           Answer
```

这是目前最接近“信息螺旋”的 IST 形式。

因为：

> **过去既不能全部丢弃，也不能全部压缩。**

它需要同时存在：

**细节证据 + 抽象历史。**
