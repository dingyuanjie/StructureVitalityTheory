# 研究实验与可证伪性协议

## 一、通用实验登记模板

| 字段 | 要求 |
|---|---|
| hypothesis_id | 唯一编号，先注册再执行 |
| system_and_boundary | 系统状态、边界、外部输入 |
| baseline | 具竞争力的已知模型，不只随机预测 |
| observable | 观测变量、量纲、数据采样率 |
| intervention | 允许怎样干预？隐藏控制变量是什么？ |
| cost | 训练/计算/能量/数据/总时间预算 |
| split | 训练、开发、验证、最终测试的锁定方式 |
| seeds | 随机种子和预设数量 |
| success_threshold | 事先定的效应与误差阈值 |
| failure_threshold | 事先说明何时判为失败 |
| artifacts | 原始数据哈希、代码commit、图、日志 |
| evidence_level | P/H/M/D/R/X/A，不自动升级 |

## H01：跨领域宏观动力学闭合

挑选3类具有明确动力学且数据可获得的系统：人造反馈电路、反应扩散格点、交通流仿真。为每类从训练集独立学习宏观变量`π_i`，在保留领域差异的同时寻找共同低维转移`Q`。基线：每领域单独的线性/非线性模型、均值、随机投影、历史统计。成功条件：未见状态分布上的误差与校准明显改善，并不依赖常值映射。失败条件：跨域共享Q系统性差于各域强基线。

## H02：结构印记的增量预测效益

固定现有观测`O`，比较含历史记忆`m`、打乱历史、同容量随机噪声记忆、额外模型参数但无记忆四组。测量`I(M;Y_future|O,E)`的估计误差及下游预测表现。用极端环境重测。失败条件：记忆仅在训练分布带来表面增益，OOD与干预无收益。

## H03：模块化在何时获得净收益

固定任务、总计算资源与通信预算，改变耦合密度、通信延迟、局部负载、集中式与分层式控制。绘制性能-成本Pareto前沿。不是预设模块化永远更好；寻找明确的交叉点和失败区。

## H04：从几何聚集到持续边界

反应扩散或两亲性模型中，分开测量聚集、封闭、非零体积、选择性通透、修复、物质/能量账本、空间步长收敛。禁止以环状热图认定已出现细胞。

## H05：生成世界递归

让宿主Python解释器执行一个有限状态虚拟世界；其规则程序再创建不同规则的世界。记录层数、实际驻留状态数、总步数、CPU时长，比较简单复制与独立子解释器的区别。禁止将“Python嵌套对象”称为意识或物理宇宙。

## H06：旧的黄金角与10^6分层假说

先锁定候选对象清单、尺度/角定义和采样方案。分别使用拟合优度和无量纲残差比较自由参数模型、对数螺旋、随机几何、其他常见分布。独立的未参与假说挑选的对象才用于最终检验。若角度/层距经常不符，记录适用范围收缩或否定。不要事后改变层级选择规则。

## H07：SVF-Net结构归纳偏置

在相同参数/FLOPs/token预算下，比较原始Attention、+学习结构势S、+随机但同容量偏置、+标准相对位置偏置。报告多seed与超出训练长度的外推。若提升仅来自额外参数或调参次数，则不支持特定SVF势场的独立价值。

## H08：IST实体检索

构造长序列实体—属性变化、同名冲突、无关扰动与正确证据缺失任务。分开写入成功、Retriever Recall、Reader恢复、Decoder EM；对比RAG/缓存/SSM/Transformer强基线。禁止Oracle Reading成绩替代真实Reader成绩。

## H09：因果可识别性

合成不同内部因果图但相同观测分布的系统，比较观测预测与主动干预后能否区分。控制干预预算和隐藏混杂。正确拒绝无法识别的机制应得到高评价，而不是被当作失败。

## H10：自动科研生成规则的能力

给智能体预先固定的模型库、可扩展语言、盲测任务、预算与日志。分别测量提出候选、产生实验、查找反例、保留历史成果、发现模型类错误、最终独立测试改进。成功必须超越随机搜索、贝叶斯优化和固定专家设计的基线；不能只看文案“提出了新理论”。

## 失败结果应怎样公布

明确失败是在假设、实现、数值收敛、数据、外推或统计检验哪一层。给出负结果不等于停止研究；相反，可缩小主张范围，成为下一轮的可用信息。
