**定位：** 面向未来人类研究者与未来AI的**可审计研究起点**，不是已证实的宇宙统一理论或正式发表论文。

## 一分钟说明

SVF关注单元、连接、边界、资源、反馈、结构形成、自维持和重组。Information Spiral关注历史信息的保留、筛选、传递、规则更新、组织层级和递归生成。2026年11月的讨论又加入**虚拟宇宙/计算嵌套**：物理世界中的计算系统可执行与自身物理定律不同的可计算虚拟规则；虚拟世界若内部具备足够的计算能力，则能继续创建子世界。注意：这种“下一个层级”是**计算生成层级**，并非证明出现新的物理宇宙。

核心三种映射：

1. **内部动力学** `T: S_t -> S_{t+1}`：同一系统中的时间更新；
2. **粗粒化/聚合** `π: X_micro -> X_macro`：宏观描述与精确/近似闭合性；
3. **生成关系** `Γ: (parent, program/resources) -> child`：已有系统创建/繁殖/实例化新的系统。

必须区分：视觉相似、拓扑相似、动力学对应、同一因果机制、同一基本物理定律。它们的证据门槛依次不同。

## 证据标签

`P` = 哲学/概念命题；`H` = 可反驳的研究假说；`M` = 在清楚假设下的数学/模型内结果；`D` = 限定数据、限定协议下的经验结果；`R` = 独立重复且达到相应学科标准的现实规律；`X` = 已知反例或否定结果；`A` = 需要原始文件再审计的历史归档事实。`M` 不是 `R`；一个被正确实现的程序也不是宇宙物理证明。

## 三项最需要纠正的误解

1. “结构生力”目前不是一个被发现的独立基本物理力；不能按此使用。\
2. “信息螺旋”可以表示历史依赖/可递归生成，不等于所有系统在几何上都呈黄金螺旋。\
3. 虚拟宇宙可以具有独立的**有效规则**，但计算资源与执行过程仍受宿主物理规律约束。

**研究态度：保留问题，让证据重塑理论；尊重最初的探索动机，也保留所有反例与失败。**
